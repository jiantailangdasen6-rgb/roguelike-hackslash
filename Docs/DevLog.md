### 決定事項（2026-10-11 のすり合わせ）
- 一番の売り：**友達とわいわい**。「わいわい」は **クラス連携** と **助け合い** で作る
- 戦闘：**手動攻撃**（照準・通常攻撃・スキル2つ・回避）。バンサバ要素は不要
- 1ランの流れ：部屋を順に攻略、3エリア×4部屋、約15分（変更なし）
- ラン中の成長：**パーク選択**（Hades の恩恵のような3択）
- ラン外の成長：**クラスごとの新パーク（技）解放・成長曲線の強化**＋**お守り（案B：効果固定の装飾品を持ち込む）**
- ハクスラ（ランダム効果の装備）：**保留**（`Core/Items` にコードだけ残してある）
- クラス制・協力（最大3人オンライン）・ファンタジー：継続
- 雰囲気：**Death Must Die に寄せる**（ダークファンタジー）
- グラフィック：**最重要**。ドット絵でキャラと敵が動的に動くこと
- 遊ぶ環境：**PC 優先**、完成後にスマホ
- ブラウザ版：GitHub Pages で公開（カードゲームと同じ方式）、協力は Relay 対応

### 感想と要望（2026-10-11、1回目のプレイ後）と対応
- 「操作性はかなり良い、グラフィックも最高」
- 倒れた仲間の位置が分かりにくい → 頭上のドクロ＋脈打つ赤い光、立つ範囲の輪、画面外は画面端に赤い矢印と距離、トースト通知
- 蘇生の残りを見たい → 頭上の蘇生ダイヤル（%）、輪の中の緑の円が広がる、仲間枠に「復活中 40%」
- 味方HPをゲージで → 左上に仲間枠（HP・シールド）、頭上に小さなHPバー
- マップにギミック・種類を → 部屋ごとに11種のレイアウト（柱・像・石棺・祭壇・長椅子・木箱・水晶）、トゲ罠・炎の噴出口・火薬樽・癒しの泉、ボスの突進を柱にぶつけるとよろめく。エリアごとに床・壁・装飾・灯りの色が変わる
- モンスターの種類を → 吸血蝙蝠・腐れ膨れ・亡者の騎士・死霊術師・怨霊、ボス「血の司教」「冥王リッチ」を追加（3エリアで別のボス）
- 難易度選択 → 見習い／標準／熟練／冥府（熟練踏破で解放）。部屋を作った人の難易度が適用。魂の欠片の倍率つき
- SE・BGMを本格的に → エディタ上で合成・リバーブをかけて書き出す方式に変更。効果音28種、BGM7曲（拠点・各エリア・ボス・勝利・敗北）。Escメニューで音量調整
- タイトル → 「Labyrinth Survivor」（PC版の保存データは旧フォルダから自動引き継ぎ）
- パークのアイコン → 全28種＋お守り8種のアイコン。選択カードと HUD に表示
- クラスごとのスキン → 各クラス4種（魂の欠片で解放、仲間の画面にも反映）

### 不具合報告と対応（2026-10-11、感想反映1回目の後）
- 蘇生サークル内でも％が増えないことがある → ホストが倒れた人の位置を倒れた瞬間で固定していた（本人は通知が届くまで動き続けるので輪とずれる）。倒れた後も位置を追い、判定を輪より 0.4 広げた
- **協力開始時、ホスト以外の画面がバグる** → 原因は3つ：
  1. **版の違う人同士で遊ぶと参加側が壊れる**：シーンを作り直すたびに RunDirector のネットワークIDが変わるため、ホストと参加者のページの版が違う（公開の更新をまたいだ）と参加側に RunDirector が現れず、HUDが空・敵が出ない。→ ビルドごとの「版の印」（`Resources/BuildStamp.txt`）を接続時に照合し、違えば「全員ページを再読み込みして部屋を作り直して」と表示して断る。ロビー右下に `ver xxxxxxxx`
  2. **ブラウザの表示**：Unity 標準のページは 1280×720 固定で、ノートPCの窓では HUD やスキル欄が切れていた → 独自テンプレート（`Assets/WebGLTemplates/Labyrinth`）で窓いっぱいに表示。UI は 1920×1080 が必ず収まる拡大方式（Expand）に
  3. **開始待ちの紺一色の画面**：ホストが全員の読み込みを待つ間、参加側はカメラに映る物がなく HUD も空だった → 「迷宮へ向かっています」の幕で覆い、始まったら消す

  全員が同じ門の前に1.2秒立つと進み、くぐった瞬間に全員が報酬を受け取る（意見が割れると進まない＝相談が生まれる）

### 協力まわりの改善と、戦闘／準備のメリハリ（2026-10-11 夜）
- 実装済み：招待リンク（部屋画面と Esc メニューでコピー、`?join=CODE` で開くとコードが入る）、ホストのタブが裏に回ると全員一時停止、途中参加と再接続（同じルームコードで自分のキャラに戻れる）、参加側の攻撃の先行表示と敵位置の先読み
- **パークの選択タイミング（決定）**：戦闘中はレベルアップしても止めず「★」で溜める → 部屋を制圧したら各自のペースで選ぶ（全員選び終えるまで門は開かない）→ 門の報酬は次の部屋に入った直後に選び、全員選ぶまで敵は出ない
- **装備（ハクスラ、2026-10-12 実装・公開済み）**：個人ドロップ／袋から自分で選んで装備（自動装備なし）／伝説装備だけキャラが光る／効果20種（基本11＋連携9）＋伝説の固有効果6種（各クラス2）／4枠（武器・防具・首飾り・指輪）／装備は準備時間に袋（I・Tab）で付け替え・「譲る」可／「宝物」の門
- **持ち越し（2026-10-12 に変更・実装・公開済み）**：最初は「見た目と図鑑だけ」だったが、ユーザーの希望で**装備を持ち越す**方式に変更。冒険で持っていた装備は全部持ち帰り（装備中＝出発時の装備、袋＝倉庫）、貸し出し品は持ち帰らない。倉庫は30枠（魂の欠片で+10ずつ、最大80。あふれた分は弱い順に自動分解）。拠点の倉庫画面（`VaultView.Open()`）で4枠に装備・分解・「並」一括分解・並べ替え。**浅い部屋では持ち込み装備の力を抑える**（部屋の番号+3のLvまで）。空き枠には冒険中だけ**貸し出し品**（並〜上質）。保存は `ProfileData.gear`（64ビットのhex）、出発時の装備は Loadout.gear でホストへ
- 公開済み（2026-10-12）：上記すべて。ドロップ率は普通3%・精鋭35%・ボス100%、分解は魂の欠片1〜8。テスト用フラグ -lootrate（ドロップ率倍率）・-openbag（準備中に袋を開く）

### 「軽く、もう一回」のための見直し（2026-10-12 のすり合わせ）
- ユーザーの方針：**軽めのプレイで「もう一回やるか」となる形**。1プレイに時間をかけすぎず、短時間でも頭をフルに使わせない。**一画面の情報量は抑える**
- 決定：
  - ランは **15分目安のまま**、ただし**ずっと戦闘にしない**（緩急をつける）
  - **全クラス共通のクエスト**（タルコフのタスクのような依頼）で報酬
  - **拠点という概念を作る**：協力プレイでも、出発前に一度拠点で準備する（モンハン型）
  - **クラスを3つ増やす**（案：守護騎士・暗殺者・錬金術師。「聖騎士」は既存の戦士スキン名と重なるので守護騎士に）
  - 装備（ハクスラ）の作業は別セッションで続ける
- 実装・公開済み（2026-10-12、作業ツリー `roguelike-hackslash-hub` → main）：
  - **歩ける拠点（Camp シーン）**：夜の礼拝堂跡の中庭。焚き火を中心に、古い鏡（クラス・見た目）／師範（熟練）／お守り職人（お守り）／迷宮の碑（難易度、ホストが選ぶ）／倉庫（装備、`VaultView`）／依頼の掲示板（墓守）。施設の前で F（Enter・パッドX、案内をクリックでも可）。**全員が門の前の輪に3秒立つと出発**。ランが終わるとホストがパーティごと拠点へ戻す（解散しない）。タイトル画面は「ひとりで遊ぶ／部屋を作る／コードで参加（＋LAN）」だけに
  - **戦闘の緩急**：各エリア4部屋 = ①殲滅 ②生存40秒（納骨堂）／精鋭の群れ（礼拝堂・奈落）③**焚き火の間**（戦闘なし。火のそばで回復・倒れた仲間も起きる、宝箱3つ＝壊すと魂、門は最初から開く）④ボス。生存は50→40秒
  - **依頼（クエスト）**：師範・お守り職人・墓守がそれぞれ連鎖の依頼を1つずつ出す（同時に最大3つ）。進行はランのイベントから各端末で数える（**仲間の戦果も全員に入る**）。達成すると画面に通知、拠点の掲示板で「受け取る」→魂の欠片（＋一部はお守り）。連鎖の後は繰り返し依頼。掲示板に「！」が出る
  - **リザルトを簡素化**：結果・1行の要約・魂の欠片・依頼1行・「拠点へ戻る」（参加者は「待っています」＋「パーティを抜ける」）
  - テスト：EditMode 98件、PlayMode 1件、`Tools/CampTest.ps1`（3人で出発→全滅→拠点へ戻る→再出発）、JoinTest・NetTest 合格
  - テスト用フラグ：`-campwait <s>`（拠点で待ってから自動出発、スクショ用）、`-wipeat <s>`（ホストが全員を倒す）、`-autoreturn`（リザルトから自動で拠点へ）
  - **新クラス3種（2026-10-12 実装・公開）**：守護騎士（鎚打ち＝強打／盾の突進＝通り道の敵を気絶／守りの陣＝5秒の聖域で被ダメ−40%と回復）、暗殺者（双剣＝凍結・気絶・印の敵に必ず会心／影渡り＝照準地点へ瞬間移動して周りを斬る／煙玉＝周りを気絶＋4秒すべて会心）、錬金術師（薬瓶投げ＝着弾で小範囲／火炎瓶＝4秒燃える床、樽にも引火／回復薬＝照準地点の仲間を回復・復活を早める）。各クラス：パーク5（うち熟練で解放2）・熟練6・スキン4・ドット絵・アイコン。**解放は依頼の報酬**：師範「納骨堂の主」→守護騎士、墓守「礼拝堂へ」→暗殺者、お守り職人「膨れの毒袋」→錬金術師（鏡では影絵＋解放条件を表示）。テスト用 `-unlockall`。新クラスの伝説装備（各2）は装備セッションが追加済み（f5e65ec。GearTests の一時緩和も元に戻した）

### 手触りの強化と音の差し替え（2026-10-12、改善案の「1」＋ユーザーの要望）
- ユーザーの選択：改善案の「1（ヒットストップと連携演出）」から着手。あわせて「効果音・BGMをもっと良いものに」→ **無料素材に差し替え**（気になる点：打撃音が軽い・BGMが単調で安っぽい・全体がピコピコ・音量のバランス）。素材9点のダウンロードはユーザーが承認
- **ヒットストップ**（`View/HitStop.cs`）：見た目だけ止める（シミュレーションと移動は止めないので協力プレイでずれない）。止まるのはドット絵のアニメ・エフェクト・敵の表示位置で、殴られた敵は小刻みに震え、止まった後に吹き飛びが一気に入る。予兆（赤い範囲）は実時間のまま。
  自分の強打 0.045秒（会心 0.065）、自分が被弾 0.04秒、砕き 0.07〜0.1秒（全員）、鎧崩し 0.06秒、ボス撃破は 0.16秒停止＋1.1秒のスロー（0.25倍）と大きな光。小さな停止は 0.12秒以上空ける（連打で引っかからない）
- **連携の見える化**：シミュレーションが「誰が凍らせた・気絶させた・印を付けたか」を覚え（`Enemy.StatusBy`）、**仲間の状態異常に乗った一撃**に `HitFlags.Teamwork`、**鎧の騎士の守りが崩れた状態への一撃**に `HitFlags.ArmorBreak` を付ける。EnemyHit の Int は下位8ビットがフラグ、上が攻撃者（`HitInfo`）。
  表示：「砕き！」（全員、氷色、大きく弾む文字）、「鎧崩し！」（全員、橙、同じ敵には3秒に1回）、「連携！」（自分が仲間の状態異常に乗ったときだけ、金色、同じ敵には2.5秒・全体で0.5秒に1回）。情報量を抑えるため文字は間引く
- **音の差し替え**（`Editor/Audio/SoundPack.cs`）：素材は `Assets/_Project/Audio/Pack/`（使う物だけ、ビルドには入らない）。効果音は素材を切り出し・重ね合わせ（例：強打＝殴打音＋肉の音＋金属音）・音程を変え、**一番大きい50ミリ秒の音量でそろえて**から `Resources/Audio/sfx_名前.wav`（＋ `_2`〜のバリエーション）に書き出す。再生時は毎回違うバリエーション。BGM は曲全体の音量をそろえて WAV で書き出す。合成音は素材が無いときの代わり
  - 割り当て：拠点 Pavane／納骨堂 In Darkness／礼拝堂 Zwischenwelt／奈落 Throne Room（以上 Of Far Different Nature）／ボス ProjectHelmet の Arcanos／勝利 Victory Stats／敗北 Obscurium の冒頭9秒。敵の攻撃の予兆は「刃を抜く音」、部屋の制圧は鐘
  - レシピを変えたら `SoundPack.Marker`（pack_vN.txt）の番号を上げる。ビルダーが無いのを見て作り直す。単独で作り直す：`powershell -File Tools/RunMethod.ps1 -Method Game.EditorTools.Audio.SoundPack.Build -Tag '\[SoundPack\]'`
  - クレジット：`Docs/credits.md` と Esc メニューの下（CC-BY の作者名表記）
