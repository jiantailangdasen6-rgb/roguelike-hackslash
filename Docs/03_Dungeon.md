# 迷宮探索型への作り替え — 設計案（すり合わせ用）

> ステータス: 案 v0.1（2026-10-12）。決まったことは「決定」、相談中は【要決定】。
> きっかけ：ユーザーの「道中が単調。大幅な変更も可（ダンジョン攻略など）」。

---

## 1. 決定済み（2026-10-12 のすり合わせ）

| 項目 | 決定 |
|---|---|
| 迷宮の形 | **部屋つなぎ型**（アイザック／ガンジョン型）。部屋が上下左右につながり、扉をくぐると隣の部屋。ミニマップあり |
| 仲間の動き | **完全にバラバラに探索できる** |
| 1ランの長さ | **15分のまま**（3エリア×各8部屋前後。全部回らなくてもボスへ行ける） |
| 見つける物 | 鍵と宝部屋／祭壇・商人・泉／仕掛け・謎解き部屋／隠し部屋・中ボス（全部入れる） |
| 離れて倒れたら | **仲間が助けに来る**（地図に赤く表示、倒れている間は狙われない、全員倒れたら全滅） |
| 戦闘中の部屋 | **後から入れる**（魔物の数は部屋にいる人数で増える） |
| 報酬の門 | **地図上の部屋に置き換える**（祠・研磨台・泉・呪いの祭壇・闇商人など） |
| 共有 | **鍵と地図は共有**。装備は今までどおり個人ドロップ |
| ボス部屋 | **全員そろって入る**（ボスの扉の前に全員が立つと開く） |
| 地図の見え方 | **入った部屋＋その隣の形**だけ見える（種類は入るまで不明）。「地図」を拾うとエリア全体が見える |
| 謎解き | **軽め**（見れば数秒で分かる仕掛け：スイッチ・罠の通路・守る・追う） |
| 進め方 | 設計案の順（①地図と移動→②バラバラ協力→③鍵・宝・中ボス・仕掛け・隠し部屋→④地図の見た目）。**区切りごとに公開**して触ってもらう |

## 2. 1エリアの姿（例）

```
          ┌───┐     ┌───┐
          │ 宝 │═鍵══│ 祠 │
          └─┬─┘     └─┬─┘
  ┌───┐   ┌─┴─┐   ┌─┴─┐   ┌───┐   ┌───┐
  │ 泉 │───│ 戦 │───│ 戦 │───│ 仕 │───│ 焚 │
  └───┘   └─┬─┘   └───┘   └─┬─┘   └─┬─┘
          ┌─┴─┐             ┌─┴─┐   ┌─┴─┐
          │ 始 │             │ 中 │   │ 主 │
          └───┘             └───┘   └───┘
  始＝入口 戦＝戦闘 仕＝仕掛け 中＝中ボス（鍵を落とす） 宝＝宝部屋（鍵で開く）
  祠＝力を選ぶ 泉＝生命 焚＝焚き火（ボスの手前） 主＝ボス  ＋どこかに隠し部屋（ひびの入った壁を壊す）
```

- 入口から**ボスまでの最短は4〜5部屋**。寄り道（祠・宝・中ボス・隠し部屋）をするほど強くなるが時間がかかる
- 部屋は毎回ランダムにつながる（形・部屋の種類・場所）。エリアごとに床・壁・灯りの色が変わるのは今と同じ
- ボスを倒すと、全員が次のエリアの入口へ

## 3. 部屋の種類（案）

| 種類 | 中身 | 時間の目安 |
|---|---|---|
| 戦闘 | 今の「群れ」を短く（2〜3波）。入った人数で魔物の数が決まる | 40〜60秒 |
| 精鋭の巣 | 精鋭が率いる群れ。倒すと良い装備が出やすい | 50秒 |
| 仕掛け・謎解き | ①**全員（ソロは1つずつ）でスイッチを踏む** ②**罠の通路を抜ける** ③**結晶を守る**（魔物が結晶を狙う） ④**逃げる宝の魔物を追う**。成功で鍵や宝 | 30〜60秒 |
| 中ボス | エリアの強い精鋭（専用の動き）。**鍵**と良い装備 | 60秒 |
| 宝部屋 | 鍵で開く。各自に装備（希少以上）か力 | すぐ |
| 祠 | 力を1つ選ぶ（今の「祝福の門」） | すぐ |
| 研磨台 | 持っている力を1段階強化 | すぐ |
| 生命の泉 | 最大HP+10%・全回復（1回だけ） | すぐ |
| 呪いの祭壇 | 力を2回選べるが、ランの間ずっと呪い | すぐ |
| 闇商人 | 魂の欠片で買う | すぐ |
| 焚き火 | ボスの手前。回復と宝箱（今の焚き火の間） | 自由 |
| 隠し部屋 | ひびの入った壁を壊すと現れる。宝箱か珍しい祠 | すぐ |
| ボス | 今のボス＋試練（不死の加護・血の儀式・奈落の崩落など） | 2〜3分 |

## 4. 協力まわり（バラバラ探索のための約束）

- **自分の部屋だけ画面に映る**（カメラは自分を追う）。仲間の位置は地図とミニマップに色つきの点、画面端に矢印
- **戦闘中の部屋**：誰でも後から入れる。出るのも自由（魔物は部屋から出ない）
- **力の選択**：レベルが上がったら、**戦闘していない部屋にいるときに**各自で選ぶ（他の人を止めない）
- **ボス部屋**：全員がボスの扉の前に立つと開く（決定）
- 倒れた仲間：地図に赤く点滅、画面端に赤い矢印と距離。倒れている間は魔物に狙われない（今と同じく、そばに立つと起きる）

## 5. 画面

- 右上に**ミニマップ**（入った部屋・見えた部屋・部屋の種類のアイコン・仲間の点・鍵の数）。M か Tab で**大きな地図**
- 扉の上に、その先がわかっていれば部屋の種類のアイコン
- 地図：入った部屋と、その隣の部屋の形が見える。種類のアイコンは入るか「地図」を拾うと出る（決定）

## 6. 作り方（技術メモ）

- エリアの全部屋を、1枚の大きな地図の上に**離して並べる**（部屋＝今の部屋の大きさ、間は通路）。シミュレーションは1つのまま、魔物・罠・宝は「どの部屋のものか」を持つ
- 部屋ごとに「眠っている／戦闘中／制圧済み」。誰かが入ると起きる。同時に動く部屋は最大3つ（3人がバラバラのとき）
- 通信：魔物のスナップショットは全部屋ぶん送る（同時に動く魔物の数は今と同程度〜3倍。既存の分割送信で足りる見込み）。地図・鍵・部屋の状態は小さな同期変数
- 今の「部屋の番号で進む」作り（`RoomIndex`、`RoomsPerArea`、報酬の門、焚き火の間、依頼の「エリアに着く」）を、地図の作りに置き換える

## 7. 進め方（案）

1. 地図の生成と部屋の移動（戦闘・祠・泉・ボス）→ ソロで遊べる形
2. バラバラ探索の協力（部屋ごとの戦闘、倒れた仲間、地図の共有）
3. 鍵・宝部屋・中ボス・仕掛け・隠し部屋
4. ミニマップと大きな地図の見た目、扉のアイコン、通路のドット絵
