### 決定事項（2026-10-11 のすり合わせ）
- 一番の売り：**友達とわいわい**。「わいわい」は **クラス連携** と **助け合い** で作る
- 戦闘：**手動攻撃**（照準・通常攻撃・スキル2つ・回避）。バンサバ要素は不要
- 1ランの流れ：部屋を順に攻略、3エリア×4部屋、約15分（変更なし）
- ラン中の成長：**パーク選択**（Hades の恩恵のような3択）
- ラン外の成長：**クラスごとの新パーク（技）解放・成長曲線の強化**＋**お守り（案B：効果固定の装飾品を持ち込む）**
- ハクスラ（ランダム効果の装備）：**保留**（`Core/Items` にコードだけ残してある）
- クラス制・協力（最大3人オンライン）・ファンタジー：継続
- 雰囲気：**Death Must Die に寄せる**（ダークファンタジー）
- グラフィック：**最重要**。ドット絵でキャラと敵が動的に動くこと
- 遊ぶ環境：**PC 優先**、完成後にスマホ
- ブラウザ版：GitHub Pages で公開（カードゲームと同じ方式）、協力は Relay 対応

### 感想と要望（2026-10-11、1回目のプレイ後）と対応
- 「操作性はかなり良い、グラフィックも最高」
- 倒れた仲間の位置が分かりにくい → 頭上のドクロ＋脈打つ赤い光、立つ範囲の輪、画面外は画面端に赤い矢印と距離、トースト通知
- 蘇生の残りを見たい → 頭上の蘇生ダイヤル（%）、輪の中の緑の円が広がる、仲間枠に「復活中 40%」
- 味方HPをゲージで → 左上に仲間枠（HP・シールド）、頭上に小さなHPバー
- マップにギミック・種類を → 部屋ごとに11種のレイアウト（柱・像・石棺・祭壇・長椅子・木箱・水晶）、トゲ罠・炎の噴出口・火薬樽・癒しの泉、ボスの突進を柱にぶつけるとよろめく。エリアごとに床・壁・装飾・灯りの色が変わる
- モンスターの種類を → 吸血蝙蝠・腐れ膨れ・亡者の騎士・死霊術師・怨霊、ボス「血の司教」「冥王リッチ」を追加（3エリアで別のボス）
- 難易度選択 → 見習い／標準／熟練／冥府（熟練踏破で解放）。部屋を作った人の難易度が適用。魂の欠片の倍率つき
- SE・BGMを本格的に → エディタ上で合成・リバーブをかけて書き出す方式に変更。効果音28種、BGM7曲（拠点・各エリア・ボス・勝利・敗北）。Escメニューで音量調整
- タイトル → 「Labyrinth Survivor」（PC版の保存データは旧フォルダから自動引き継ぎ）
- パークのアイコン → 全28種＋お守り8種のアイコン。選択カードと HUD に表示
- クラスごとのスキン → 各クラス4種（魂の欠片で解放、仲間の画面にも反映）

### 不具合報告と対応（2026-10-11、感想反映1回目の後）
- 蘇生サークル内でも％が増えないことがある → ホストが倒れた人の位置を倒れた瞬間で固定していた（本人は通知が届くまで動き続けるので輪とずれる）。倒れた後も位置を追い、判定を輪より 0.4 広げた
- **協力開始時、ホスト以外の画面がバグる** → 原因は3つ：
  1. **版の違う人同士で遊ぶと参加側が壊れる**：シーンを作り直すたびに RunDirector のネットワークIDが変わるため、ホストと参加者のページの版が違う（公開の更新をまたいだ）と参加側に RunDirector が現れず、HUDが空・敵が出ない。→ ビルドごとの「版の印」（`Resources/BuildStamp.txt`）を接続時に照合し、違えば「全員ページを再読み込みして部屋を作り直して」と表示して断る。ロビー右下に `ver xxxxxxxx`
  2. **ブラウザの表示**：Unity 標準のページは 1280×720 固定で、ノートPCの窓では HUD やスキル欄が切れていた → 独自テンプレート（`Assets/WebGLTemplates/Labyrinth`）で窓いっぱいに表示。UI は 1920×1080 が必ず収まる拡大方式（Expand）に
  3. **開始待ちの紺一色の画面**：ホストが全員の読み込みを待つ間、参加側はカメラに映る物がなく HUD も空だった → 「迷宮へ向かっています」の幕で覆い、始まったら消す

### 部屋の分岐選択とパーク・お守りの追加（2026-10-11、DevLog 次の候補2）
- ソースを GitHub に置いた（最初は非公開で作成 → 別セッションで公開に。ユーザーが「公開で問題ない」と確認）
- **報酬の門**（Hades 型）：部屋を制圧すると奥の壁沿いに門が2つ（エリア2以降は35%で3つ）。渦の中に報酬の印、下に名前と効果。
  全員が同じ門の前に1.2秒立つと進み、くぐった瞬間に全員が報酬を受け取る（意見が割れると進まない＝相談が生まれる）
  - 祝福（パーク3択をもう1回）／研磨（持っているパークを1段階強化。強化できる物がない人は祝福）／生命（最大HP+10%＋全回復）／魂の欠片（8＋4×エリア）
  - 試練の門（40%で1つ、赤い門とドクロ）：報酬2倍、次の部屋は魔物HP×1.35・攻撃×1.15・精鋭+15%。HUDに「試練」
  - ボス前の部屋は必ず「生命」を含み、試練は出ない
  - 報酬の選択はレベルアップより先に出す（選択画面の見出しが「祝福／研磨」になる）
- パーク7種追加（共通：処刑人・魂喰らい・戦友・加護、戦士：地割れ、魔法使い：氷の鎧、狩人：跳弾）。戦友・氷の鎧は協力向け
- お守り4種追加（魂の灯籠40・骨のさいころ70・古の魔導書90・血の聖杯100）。拠点のお守り欄は2列のカードに（カードを押すと装備／解放）
- アイコン：新パーク7・新お守り4・門の報酬5（祝福の光輪、研磨の剣と矢印、生命のハート、魂の欠片の水晶、試練のドクロ）
- テスト用フラグ `-doorwait <s>`：ボットが門の前で待つ（スクショ用）

### 協力まわりの改善と、戦闘／準備のメリハリ（2026-10-11 夜）
- 実装済み：招待リンク（部屋画面と Esc メニューでコピー、`?join=CODE` で開くとコードが入る）、ホストのタブが裏に回ると全員一時停止、途中参加と再接続（同じルームコードで自分のキャラに戻れる）、参加側の攻撃の先行表示と敵位置の先読み
- **パークの選択タイミング（決定）**：戦闘中はレベルアップしても止めず「★」で溜める → 部屋を制圧したら各自のペースで選ぶ（全員選び終えるまで門は開かない）→ 門の報酬は次の部屋に入った直後に選び、全員選ぶまで敵は出ない
- **装備（ハクスラ、2026-10-12 実装・公開済み）**：個人ドロップ／袋から自分で選んで装備（自動装備なし）／伝説装備だけキャラが光る／効果20種（基本11＋連携9）＋伝説の固有効果6種（各クラス2）／4枠（武器・防具・首飾り・指輪）／装備は準備時間に袋（I・Tab）で付け替え・「譲る」可／「宝物」の門
- **持ち越し（決定）**：装備の強さは持ち越さず、見た目と図鑑だけ残す。装備はデータごと保存できる形にしておき、あとで「持ち越しあり」に変えられるようにする
- 公開済み（2026-10-12）：上記すべて。ドロップ率は普通3%・精鋭35%・ボス100%、分解は魂の欠片1〜8。テスト用フラグ -lootrate（ドロップ率倍率）・-openbag（準備中に袋を開く）
- 並行作業：別セッション（作業ツリー `D:projectoguelike-hackslash-hub`、ブランチ hub）が歩ける拠点・戦闘なしの部屋・依頼人NPC・新クラス3種を担当。push の前は `git pull`、公開は origin/main を取り込んでから

### Claude が自分の判断で決めたこと（ユーザーが変更可）
- 報酬の種類と量（生命+10%、魂の欠片 8+4×エリア）、試練の強さと出現率、門の数、「全員が同じ門」ルール、報酬は門をくぐった時点で受け取る
- 新パーク・新お守りの名前と数値・価格
- エリア名（朽ちた納骨堂／血塗られた礼拝堂／奈落の玉座）、ボス名、新しい敵の名前と性能、スキン名と価格（60/90/120）
- 「冥府」難易度は熟練クリアで解放
- 亡者の騎士は「凍結・気絶・印」で鎧を崩す設計（連携を促すため）
- 罠は魔物にも効く（誘い込みで助け合い・わいわい感を出すため）
- 魔法使い等のスキル1は右クリックにも割り当て
- 協力の参加方式：ルームコード（Relay）。PC版のみ LAN の IP 直結も残す
- BGM・効果音は自作合成（外部素材のダウンロードはしていない）。初期音量 BGM 30%・効果音 40%（ユーザーの「うるさい」を受けて下げた）


### 作業の進め方（ユーザーの指示、2026-10-11）
- **変更はすべてブラウザ版に反映する**（毎回の確認は不要）：検証が済んだら `Tools/BuildWeb.ps1` → `Tools/DeployWeb.ps1` → `Tools/CrossTest.ps1`
- ソースのリポジトリをどこかへ push するときは事前に確認する
- **テスト中は音を出さない**：`-autoquit`／`-botmove`／`-mute`（ブラウザは `?botmove`／`?mute`）で自動的に無音。Edge は `--mute-audio`。新しいテスト用スクリプトも必ずこれらを付ける
- **ゲームの初期音量は小さめ**（BGM 30%、効果音 40%。`AudioPrefs`）。上げるときは相談する

## 3. 実装済みの中身

- **クラス**：戦士（3連撃／突進斬り／鬨の声）、魔法使い（魔弾／氷結陣／癒しの光）、狩人（速射／貫通の一矢／狩人の印）。各4スキン
- **連携**：凍結した敵を強打で「砕く」、印で全員のダメージ増、鬨の声で仲間を強化、鎧の騎士を崩す。蘇生（そばに立つ）、癒しの光・癒しの泉
- **敵**：9種＋ボス3体（エリアごと）。攻撃前に必ず予兆（扇／円／線／四角）。出現前に赤い魔法陣
- **部屋**：11レイアウト、トゲ罠・炎・火薬樽・癒しの泉、遮蔽物、エリアごとの見た目
- **成長**：パーク34種、成長曲線、熟練（クラス別6ノード）、お守り12種、魂の欠片、スキン、難易度
- **部屋の分岐**：制圧後に報酬の門（祝福・研磨・生命・魂の欠片）が2〜3つ。全員で同じ門に立って進む。試練の門（報酬2倍・魔物強化）、ボス前は必ず生命の門
- **画面**：拠点（クラス・スキン・難易度・お守り・熟練・ソロ/オンライン/LAN）、HUD（仲間枠・パークアイコン）、仲間マーカー、パーク3択（アイコン付き）、Escメニュー（音量）、リザルト
- **演出**：コード生成のドット絵とアニメ、ろうそくの灯り（エリア色）、ブルーム・周辺減光、画面揺れ、火の粉、爆発・炎・聖光、合成BGM・効果音
- **ブラウザ対応**：同梱の日本語サブセットフォント、ソロは SinglePlayerTransport、保存は PlayerPrefs、Relay は wss

## 4. 既知の課題・未確認

- **バランスは仮**（新しい敵・罠・難易度を含め、人が遊んだ感想で調整したい）
- BGM・効果音は数値解析（音割れ・音量・構成）でしか確認していない。耳での確認はユーザー頼み
- **ブラウザ版のホスト（部屋を作る側）**は未確認（PCホスト＋ブラウザ参加は確認済み）
- ブラウザ版はタブを裏に回すと止まる（ホストが裏に回ると全員止まる）
- 操作は PC 前提。スマホのブラウザでは開けるが遊びにくい
- ドット絵は自前生成（気になる箇所は個別に描き直せる）
- ソースは GitHub の公開リポジトリにある（誰でも読める。秘密情報を入れないこと）

## 6. 再開するときのコマンド

```
powershell -File Tools/VerifyAll.ps1        # ゲーム生成＋テスト＋Windowsビルド＋3人通信テスト
powershell -File Tools/BuildWeb.ps1         # フォント＋ゲーム生成＋テスト＋WebGLビルド
powershell -File Tools/DeployWeb.ps1        # ブラウザ版を GitHub Pages へ公開（公開済みの場所へ上書き）
powershell -File Tools/OnlineTest.ps1       # Relay：Windows 3台
powershell -File Tools/CrossTest.ps1        # Relay：Windowsホスト＋ブラウザ参加
powershell -File Tools/Screenshots.ps1 -Class mage -Times "10,22,34"   # スクショ（Logs/shots/）。-Extra "-startroom 7" でボス部屋など
powershell -File Tools/RunMethod.ps1 -Method Game.EditorTools.Audio.AudioGenerator.Generate   # BGM・効果音を作り直す
```
- Unity エディタでこのプロジェクトを開いていると、バッチ実行は失敗する
- 日本語の文言を増やしたら `Tools/SubsetFonts.ps1` を流し直す（ブラウザで文字が出なくなる）
