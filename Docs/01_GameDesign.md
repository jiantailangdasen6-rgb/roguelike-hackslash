## 2. 舞台設定（たたき台）

冒険者たちは富と名声を求めて挑み、そして帰ってこない──。主人公たちは迷宮の入口にある拠点の村から何度も挑戦する。
（「死んでも拠点に戻る」理由付けは【要決定】: 女神の加護で蘇る / 迷宮の呪いでループしている など）

## 3. コアループ

```
 ┌──────────────┐
 │ 拠点（ロビー）│ ← クラス選択・装備の付け替え・仲間と合流
 └──────┬───────┘
        ▼
 ┌──────────────┐   部屋 = 大群が押し寄せるアリーナ
 │ 迷宮の部屋    │   「生き残る」or「指定数を倒す」で出口が開く
 │   × 数部屋    │   → 出口に入って次の部屋へ（難度上昇）
 └──────┬───────┘
        ▼
 ┌──────────────┐
 │ エリアボス    │ × 3 エリア → 最終ボス（計 約15分）
 └──────┬───────┘
        ▼
  全滅 or クリア → 拾った装備はすべて持ち帰り → 拠点で装備を付け替えて再挑戦
```

| ループ | 長さ | 中身 |
|---|---|---|
| 短期 | 数秒 | 移動して群れを避け、自動攻撃で倒し、経験値ジェムを拾う |
| 中期 | 1ラン（15分） | レベルアップ 3 択で武器・パッシブを育て、ビルドを完成させてボスを倒す |
| 長期 | 複数ラン | 装備を掘って育てる（ハクスラ）。クラス・武器・難易度のアンロック |

## 4. 操作

| 操作 | PC（KB） | パッド | スマホ |
|---|---|---|---|
| 移動 | WASD / 矢印 | 左スティック | バーチャルスティック |
| 攻撃 | **自動** | **自動** | **自動** |
| ダッシュ | Space | A | DASH ボタン |
| 装備画面 | I / Tab | Select | バッグボタン |

- 操作は「移動（＋ダッシュ）」だけ。攻撃は武器ごとのクールダウンで自動発動
- スマホでも PC と同じ体験ができるのがこのジャンルの強み

## 6. ラン中の成長（ローグライト部分）

### 6.1 経験値・レベル
- 敵が落とす**経験値ジェム**を拾う。**経験値はチーム共通**
- チームのレベルが上がると、**各プレイヤーが自分用の 3 択**から 1 つ選ぶ
  - 協力時は全員が選び終わるまでゲームが一時停止（一定時間で自動選択）

### 6.2 レベルアップの選択肢
- **武器の追加**（最大 6 枠）/ **武器の強化**（Lv1〜5）/ **パッシブ**（最大HP・移動速度・攻撃力・クールダウン・範囲・回収範囲・防御・自然回復）

### 6.3 武器（試作分）
| 武器 | 動作 | 強化で伸びる所 |
|---|---|---|
| 大剣 | 向いている方向を扇状になぎ払う | ダメージ・範囲 |
| 投げ斧 | 最寄りの敵へ斧を投げる（貫通） | 本数・貫通数 |
| 聖なるオーラ | 自分の周囲に継続ダメージ | 範囲・ダメージ |

## 7. ハクスラ部分（装備）

### 7.1 装備スロット
- **兜 / 鎧 / 指輪 / 首飾り** の 4 枠（武器はラン中のレベルアップで得るため、装備は「ステータスと特殊効果」を担当）

### 7.2 レアリティ
| レアリティ | 色 | ランダム効果の数 |
|---|---|---|
| コモン | 白 | 0〜1 |
| マジック | 青 | 1〜2 |
| レア | 黄 | 3〜4 |
| レジェンダリー | 橙 | 固有効果 ＋ 3〜4（後で） |

### 7.3 ランダム効果（アフィックス）の例
- 攻撃力 +X% / 最大HP +X / 移動速度 +X% / クールダウン −X% / 攻撃範囲 +X% / 回収範囲 +X% / 防御 +X / 自然回復 +X/秒
- （後で）特定武器の強化、撃破時に爆発、低HP時に攻撃力アップ、など

### 7.4 ドロップと持ち帰り
- エリート・ボス・宝箱、低確率で通常敵から
- **ドロップは各プレイヤーに個別**（他人には見えない。取り合いなし）
- 拾った装備は**すべて持ち帰り**（全滅しても失わない）。装備は自分の端末に保存
- 深く潜るほど / 難易度が高いほどアイテムレベルとレアリティが上がる

## 8. 迷宮の構成

- 3 エリア × 各 3 部屋 ＋ エリアボス、最後に最終ボス（目安: 1部屋 60〜90 秒 → 合計 約15分）
- 部屋のクリア条件: **一定時間生き残る** or **指定数を倒す**
- （後で）出口が複数あり、報酬の種類（装備 / 回復 / 経験値 / 呪いと引き換えの強化）を見て選ぶ

| # | エリア（案） | 主な敵 | ボス（案） |
|---|---|---|---|
| 1 | 苔むした遺跡 | スライム、ゴブリン、キノコ | ゴブリンキング |
| 2 | 地下墓所 | スケルトン、ゴースト、ネクロマンサー | 骸骨騎士 |
| 3 | 溶岩の深淵 | インプ、ゴーレム、魔導士 | 炎竜 |
| 最終 | 封印の間 | — | 迷宮の主【要決定】 |

### 敵のタイプ
| タイプ | 行動 | 例 |

| 群れ型 | まっすぐ寄ってくる。数で押す | スライム、コウモリ |
| 射撃型 | 距離を取って弾を撃つ | ゴブリン弓兵、魔導士 |
| 突進型 | 溜めてから突っ込む | イノシシ |
| 自爆型 | 近づいて爆発 | 爆弾キノコ |
| エリート | 通常敵に強化効果が付く。装備ドロップ率が高い | — |

## 9. 協力プレイ

| ルール | 内容 |
|---|---|
| 人数 | 1〜3 人。ホストが部屋を立て、他の人が参加 |
| 経験値 | チーム共通。レベルアップ時は各自が自分の 3 択を選ぶ |
| ドロップ | 各自に個別 |
| ダウンと蘇生 | HP 0 でダウン。仲間が近くに数秒いると蘇生。全員ダウンで全滅 |
| 難易度 | 人数に応じて敵の出現数・HP が増える |
| 接続 | 試作は同じ Wi-Fi 内で IP 指定。後でインターネット越し（Unity Relay + ルームコード）に対応 |
