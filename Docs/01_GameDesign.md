## 1. コンセプト

| 項目 | 内容 |
|---|---|
| ジャンル | 見下ろし型 2D ハクスラ × ローグライク |
| プラットフォーム | PC（キーボード＋マウス / ゲームパッド）、スマホ（iOS / Android） |
| エンジン | Unity 6（6000.6.2f1）/ C# |
| 1ランの長さ | 20〜30分（スマホで遊べるよう、フロア単位で中断・再開できる） |

### 参考作品
- **Hades / Enter the Gungeon / Soul Knight** — 見下ろし視点の部屋クリア型ローグライク、操作感
- **Diablo / Path of Exile** — ランダムアフィックス付き装備、レアリティ、ドロップの気持ちよさ
- **Soul Knight / Archero** — スマホでの操作系（バーチャルスティック＋オートエイム）

### 世界観・アートスタイル
- **世界観: ファンタジー**（決定 2026-10-06）
- トーン【要決定】: 王道ファンタジー（明るめ・冒険感） / ダークファンタジー（重め・退廃的） / ポップ（デフォルメ・コミカル）
- アート: ドット絵（16×16 or 32×32）を想定。開発初期は仮素材（単色の四角・円）で進める

### 舞台設定（たたき台）
地下深くへと続く古の大迷宮。最深部には災いの元凶が眠るとされ、
冒険者たちは富と名声を求めて挑み、そして帰ってこない──。主人公は迷宮の入口にある拠点の村から何度も挑戦する。
（「死んでも拠点に戻る」理由付けは【要決定】: 女神の加護で蘇る / 迷宮の呪いでループしている など）

## 2. コアループ

```
 ┌────────────┐
 │   拠点     │ ← 恒久強化・キャラ/武器アンロック
 └─────┬──────┘
       ▼
 ┌────────────┐   部屋を攻略 → 報酬 → 次の部屋
 │ ダンジョン  │   （戦闘 / 宝 / ショップ / イベント）
 │  フロア1〜N │
 └─────┬──────┘
       ▼
 ┌────────────┐
 │   ボス     │
 └─────┬──────┘
       ▼
  死亡 or クリア → 持ち帰り素材で拠点を強化 → 再挑戦
```

- **短期ループ（数十秒）**: 部屋に入る → 敵を倒す → ドロップを拾う
- **中期ループ（1ラン）**: 装備・スキル・レリックを集めてビルドを完成させ、ボスを倒す
- **長期ループ（複数ラン）**: 素材を持ち帰って恒久アンロック・難易度解放

## 3. 操作

| 操作 | PC（KB+M） | PC（パッド） | スマホ |
|---|---|---|---|
| 移動 | WASD | 左スティック | 左側バーチャルスティック |
| 照準 | マウス方向 | 右スティック | **オートエイム**（最寄りの敵） |
| 通常攻撃 | 左クリック（長押しで連続） | RT | 攻撃ボタン（長押しで連続） |
| 回避（ダッシュ） | Space | A | 回避ボタン |
| スキル1 / 2 | Q / E | LB / RB | スキルボタン×2 |
| インタラクト | F | X | 近づくと自動表示されるボタン |
| ポーション | R | Y | ポーションボタン |

- スマホは「移動に集中、攻撃はオートエイム」が基本。PCでもオートエイムをオプションで選べるようにする

## 4. ハクスラ要素（装備・ドロップ）

### 4.1 装備スロット
- **武器**（攻撃モーション・射程・基本ダメージを決定）
- **防具**（胴）
- **アクセサリ** ×2

### 4.2 武器種（初期案）
| 武器 | 特徴 |
|---|---|
| 剣 | 扇状の近接攻撃、バランス型 |
| 槍 | 前方直線の長いリーチ |
| 弓 | 遠距離・単体 |
| 杖 | 遠距離・範囲（弾が爆発） |

### 4.3 レアリティ
| レアリティ | 色 | アフィックス数 |
|---|---|---|
| コモン | 白 | 0 |
| マジック | 青 | 1〜2 |
| レア | 黄 | 3〜4 |
| レジェンダリー | 橙 | 固有効果 ＋ 2〜3 |

### 4.4 アフィックス（ランダム付与効果）の例
- 攻撃力 +X% / 攻撃速度 +X% / クリティカル率 +X%
- 最大HP +X / 移動速度 +X%
- 攻撃時 X% で燃焼付与 / 敵撃破時に HP 回復
- 回避後 2 秒間ダメージ +X%

### 4.5 ハクスラとローグライクの両立【要決定】
ローグライクは「ランごとにリセット」、ハクスラは「装備を育てる」ので相性の調整が必要。

- **案A（推奨）**: ラン中の装備はラン終了でリセット。代わりに「素材・通貨」を持ち帰り、拠点で恒久強化
- **案B**: ランで拾った装備を **1つだけ** 持ち帰れる（倉庫）。持ち込みは次ランの初期装備に
- **案C**: 装備は全部持ち帰り（ハクスラ寄り）。ダンジョンの難易度段階（ティア）を上げていく

## 5. ローグライク要素

### 5.1 ダンジョン生成
- 1 フロア = 部屋のグラフ（10〜15部屋）。部屋同士を通路/扉でつなぐ
- 部屋は「手作りテンプレート」をランダムに組み合わせる方式（品質と多様性のバランス）
- 部屋の種類

| 部屋 | 内容 |
|---|---|
| スタート | 安全地帯 |
| 戦闘 | 敵をすべて倒すと扉が開く。ウェーブ制あり |
| エリート | 強化された敵＋良いドロップ |
| 宝箱 | 装備確定ドロップ |
| ショップ | ゴールドで装備・回復を購入 |
| イベント | 祭壇（呪いと引き換えに強化）など |
| ボス | フロア最後 |

### 5.2 ラン構成（初期案）
- バイオーム 3 つ × 各 2〜3 フロア ＋ 最終ボス
- 深く潜るほど敵が強くなり、ドロップのレアリティ・アイテムレベルが上がる

| # | バイオーム（案） | 雰囲気 | 主な敵 | ボス（案） |
|---|---|---|---|---|
| 1 | 苔むした遺跡 | 緑・石造り・木漏れ日 | スライム、ゴブリン、キノコ | ゴブリンキング |
| 2 | 地下墓所 | 青白い灯火・骨・棺 | スケルトン、ゴースト、ネクロマンサー | 骸骨騎士 |
| 3 | 溶岩の深淵 | 赤黒い岩・溶岩・魔法陣 | インプ、ゴーレム、魔導士 | 炎竜 |
| 最終 | 封印の間 | — | — | 迷宮の主【要決定】 |

### 5.3 ラン中の成長
- **装備**（上記ハクスラ要素）
- **レベルアップ**: 敵撃破で経験値 → レベルアップ時に 3 択の強化（パッシブ）を選択
- **レリック**: 宝箱・ボス報酬。ビルドの方向性を決める強力なパッシブ

### 5.4 パーマデス & メタ進行
- 死亡するとランは終了（スマホ向けに「フロア開始時点で中断セーブ」は可能）
- 持ち帰り素材で: 初期HP強化 / 新武器・新キャラのアンロック / 新レリックの出現解放 / 難易度（ヒート）解放

## 6. 敵

| タイプ | 行動 | 対処 | ファンタジーでの例 |
|---|---|---|---|
| 突進型 | 近づいて体当たり | 回避で避ける | スライム、イノシシ、ゴブリン戦士 |
| 射撃型 | 距離を取って弾を撃つ | 詰めて倒す | ゴブリン弓兵、スケルトンアーチャー、魔導士 |
| 自爆型 | 近づいて爆発 | 遠距離で処理 | 爆弾キノコ、ボムインプ |
| 召喚型 | 雑魚を呼ぶ | 優先して倒す | ネクロマンサー、ゴブリンシャーマン |
| 盾持ち | 正面ガード | 背後から攻撃 | スケルトン盾兵、ゴーレム |

- **エリート**: 通常敵にランダムな修飾（高速・分裂・反射 など）が付く。ハクスラのアフィックスと同じ仕組みを流用
- **ボス**: バイオームごとに 1 体。HP 段階でパターン変化
