## 1. コンセプト

**「友達とわいわい、闇の迷宮を手動アクションで攻略する協力ローグライト」**

| 項目 | 内容 |
|---|---|
| ジャンル | 見下ろし型 2D アクション ローグライト（手動攻撃） |
| 一番の売り | **友達とわいわい遊べること**（クラス連携・助け合い） |
| 協力プレイ | オンライン最大 3 人（ソロも可） |
| プラットフォーム | **PC が先**。完成後にスマホへ |
| 1ランの長さ | 約 15 分 |
| 世界観・雰囲気 | ダークファンタジー。**雰囲気は Death Must Die に寄せる** |
| グラフィック | **最重要**。ドット絵、キャラ・敵が動的に動く、暗く重い色調に赤と金の差し色、灯りの演出 |
| 近い作品 | Death Must Die（雰囲気）、Ravenswatch / Windblown（協力アクション）、Hades（パーク） |

## 2. コアループ

```
 拠点（クラス選択・お守り・熟練）
      │
      ▼
 迷宮の部屋（ウェーブ殲滅 / 一定時間生存 / ボス）× 4 部屋 × 3 エリア ≒ 15 分
      │  敵を倒す → 魂が出る → チームレベル UP → 各自パークを 3 択で選ぶ
      │  部屋を制圧 → 報酬の門が 2〜3 つ開く → 全員で選んだ門をくぐる → 報酬
      ▼
 全滅 or 踏破 → 魂の欠片を獲得 → 拠点で熟練・お守りを解放 → 再挑戦
```

## 4. クラス（連携と助け合いが軸）

| クラス | 役割 | 通常攻撃 | スキル1 | スキル2 |
|---|---|---|---|---|
| 戦士 | 前衛・連携の要 | 3 連撃（3 撃目は強打） | 突進斬り（無敵で突っ込む） | 鬨の声（敵を気絶＋仲間の攻防アップ） |
| 魔法使い | 凍結と回復の支援 | 魔弾 | 氷結陣（範囲の敵を凍らせる） | 癒しの光（回復・復活を早める） |
| 狩人 | 遠距離・弱点を暴く | 速射 | 貫通の一矢（強打・貫通） | 狩人の印（受けるダメージ +35%） |

### 連携（わいわいの核）
- **砕き**：凍った敵に強打（戦士の斬撃・突進、狩人の貫通の一矢）→ ダメージ 2.5 倍＋周囲に破片
- **印**：狩人が付けた印で、全員のダメージが上がる
- **鬨の声**：戦士の周りの仲間が強化される
- **助け合い**：倒れた仲間のそばに立つと復活。魔法使いの癒しの光で回復＆復活を早める

## 5. ラン中の成長（パーク）
- 敵が落とす**魂**を拾うと**チームの経験値**が貯まる（全員共通）
- レベルアップで各自が **3 択のパーク**から 1 つ選ぶ（全員選ぶまで一時停止）
- パークは「共通」と「クラス専用」（全34種）。例：旋風（3 撃目が回転斬り）、多重詠唱、散射、共鳴（状態異常の敵へのダメージ増＝連携強化）、守護の絆（復活支援）
  - 追加（2026-10-11）：処刑人（瀕死の敵に強い）、魂喰らい（魂の回収範囲＋回復）、戦友（近くの仲間の数だけ攻撃力アップ）、加護（部屋ごとにシールド）、
    地割れ（戦士：突進斬りの終わりに周囲を気絶）、氷の鎧（魔法使い：凍結陣の周りの仲間にシールド）、跳弾（狩人：矢が別の敵へ跳ねる）
- レベルが上がるとクラスごとの**成長曲線**で HP・攻撃力も自動で伸びる

### 部屋の分岐（報酬の門、Hades 型）
- 部屋を制圧すると奥の壁に**門が 2 つ（エリア2以降は時々 3 つ）**開く。門の渦の中に報酬の印、下に名前と効果
- **全員が同じ門の前に立つ**と進む（意見が分かれると進まない＝相談する）。報酬は門をくぐった瞬間に全員が受け取る
  - **祝福**：パークを 3 択でもう 1 つ ／ **研磨**：持っているパークを 1 段階強化（強化できる物がない人は祝福）
  - **生命**：最大HP +10%（ラン中ずっと）と全回復 ／ **魂の欠片**：ラン後の魂の欠片 +（8＋4×エリア）
- **試練の門**（赤、ドクロ印）：報酬 2 倍。そのかわり次の部屋の魔物が HP×1.35・攻撃×1.15、精鋭が出やすい
- **ボス部屋の前は必ず生命の門がある**（回復して挑むか、強くなって挑むか）。ボス前に試練は出ない

## 6. ラン外の成長
- ランの成果に応じて**魂の欠片**を獲得（部屋・ボス・討伐数・踏破）
- **熟練（クラスごと）**：新しい技（パーク）の解放、成長曲線の強化（HP 成長・攻撃成長）、ステータス強化、「開始時にパークを 1 つ選べる」
- **お守り（案B）**：効果固定の装飾品を 2 つ持ち込む（全12種：HP+15%、ダメージ+10%、復活速度+60%、1 回だけ自動復活、
  魂の灯籠（回収範囲+60%）、骨のさいころ（会心+10%）、古の魔導書（範囲+15%）、血の聖杯（ダメージ+25%・最大HP−15%） など）
- **スキン**：クラスごとに4種類の見た目（色違い）。魂の欠片で解放し、仲間の画面にも反映
- ランダム効果付きの装備（ハクスラ）は**保留**

## 7. 迷宮

| エリア | 名前 | 見た目 | 主な敵 | ボス |
|---|---|---|---|---|
| 1 | 朽ちた納骨堂 | 灰色の石、骨、ろうそく | スケルトン兵、骸骨弓兵、グール、吸血蝙蝠 | 骸骨の騎士王 |
| 2 | 血塗られた礼拝堂 | 赤い絨毯、ステンドグラス、赤いろうそく | ＋ 狂信者、腐れ膨れ、亡者の騎士 | 血の司教 |
| 3 | 奈落の玉座 | 黒曜石、紫に光る亀裂と水晶、鎖 | ＋ 死霊術師、怨霊 | 冥王リッチ |

- 各エリア 4 部屋：①ウェーブ殲滅 ②50 秒生存 ③精鋭入りのウェーブ ④ボス
- 部屋ごとに**地形（レイアウト）**が変わる：柱・像・石棺・祭壇・長椅子・木箱・水晶（高い物は飛び道具を遮る＝遮蔽物）
- **ギミック**（魔物にも効く → 誘い込んで利用できる）
  - トゲ罠：周期的に揺れて予告 → トゲが出る
  - 炎の噴出口：壁際から一直線に炎（予告の帯が出る）
  - 火薬樽：攻撃すると導火線 → 爆発（魔物も味方も巻き込む、連鎖する）
  - 癒しの泉：上に立つと周りの仲間ごと回復（部屋に 1 回）
  - ボスの突進を柱にぶつけると、しばらくよろめく
- 敵は**攻撃前に必ず予兆**（赤い扇形・円・線・四角）を出す。出現前に赤い魔法陣
- 人数・**難易度**に応じて敵の数・HP・攻撃力が増える

### 難易度（ホストが拠点で選ぶ）
| 難易度 | 内容 | 魂の欠片 |
|---|---|---|
| 見習い | 敵HP×0.7、攻撃×0.6、数×0.85 | ×0.7 |
| 標準 | 本来の迷宮 | ×1 |
| 熟練 | 敵HP×1.35、攻撃×1.35、数×1.15 | ×1.5 |
| 冥府 | 敵HP×1.8、攻撃×1.7、数×1.3（熟練の踏破で解放） | ×2.2 |

## 8. 演出・UI（協力プレイ向け）
- 倒れた仲間：頭上のドクロと赤く脈打つ光、立つべき範囲の輪、蘇生ダイヤル（何%か）、画面外なら画面端に赤い矢印と距離
- 味方の HP：画面左上の仲間枠（HP・シールド・瀕死/復活中%）＋頭上の小さな HP バー
- パーク：選択カードと HUD にアイコン
- 初めて出る敵・ギミックは一度だけヒントを表示
- 音：効果音約30種と BGM 7 曲（拠点・3エリア・ボス・勝利・敗北）をエディタ上で合成して書き出し。音量は Esc メニューで調整
